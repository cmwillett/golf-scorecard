Example Workflow

  1. Tap Host Round and enter the host PIN.
  2. Create the round with the course, game style, holes, teams, and players.
  3. After creation, write down or copy the Join Code.
  4. Send the Join Code to everyone playing.
  5. Send each team only their own team PIN.
  6. Each team taps Join Round, enters the Join Code, chooses their team, and enters their team PIN.
  7. Teams enter their own scores during the round.
  8. Anyone can tap View Leaderboard and enter the Join Code to follow the live standings.
  9. Use this Admin page to view PINs again, reset a team PIN, lock scoring, reopen scoring, or delete a test round.
